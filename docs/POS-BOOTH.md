# POS-ออกบูท — คู่มือติดตั้ง

หน้าใหม่ใต้เมนู **Marketing ▾ → POS-ออกบูท** (`/pos-booth`) สำหรับขายหน้าบูท
พร้อมหน้ารายงาน (`/pos-booth/report`)

ระบบนี้ **เพิ่มของใหม่อย่างเดียว** ไม่แก้หรือลบหน้าเดิม และไม่แตะข้อมูลเดิม
(Sales Order, PR, Memorandum, Records, Requests, ผู้ใช้ ฯลฯ)

## ขั้นตอนติดตั้ง (ทำครั้งเดียว)

### 1. สร้างตารางใน Supabase
Supabase → SQL Editor → New query → วางเนื้อหาไฟล์
`supabase/migrations/0011_pos_booth.sql` → Run

- สร้างเฉพาะตารางใหม่ชื่อขึ้นต้น `pos_` (pos_shifts, pos_bills, pos_bill_items,
  pos_expenses, pos_bill_counters)
- รันซ้ำได้ ไม่เสียหาย

### 2. ตั้งค่าส่งอีเมล์สรุป (ฟรี ส่งจาก maeicemahachai@gmail.com)
ทำตามคำอธิบายด้านบนของไฟล์ `apps-script/pos-email.gs` แล้วใส่ใน
Vercel → trc-portal → Settings → Environment Variables:

| ชื่อ | ค่า |
|---|---|
| `POS_EMAIL_WEBHOOK_URL` | URL ของ Apps Script (ลงท้าย `/exec`) |
| `POS_EMAIL_WEBHOOK_SECRET` | รหัสลับ ตัวเดียวกับใน Script properties |

ถ้ายังไม่ตั้งค่า ระบบยังปิดร้านและบันทึกยอดได้ตามปกติ แค่จะแจ้งว่าส่งอีเมล์ไม่สำเร็จ

### 3. Deploy
Merge branch `feature/pos-booth` → Vercel deploy อัตโนมัติ

## ใครใช้ได้
สมาชิกฝ่าย Marketing และ admin (เหมือนเมนู Sales Order)

## การทำงาน
- **เปิดร้าน:** ชื่องาน Event + เงินทอนตั้งต้น ส่วนชื่อพนักงานดึงจากบัญชีที่ล็อกอิน
  แต่ละคนเปิดร้านค้างได้ครั้งละ 1 รอบ ถ้ารีเฟรชหน้าหรือปิดเบราว์เซอร์ จะกลับมาที่รอบเดิม
- **ขาย:** บิล 1, 2, 3… บิลที่ยังไม่จ่ายเก็บไว้ในเบราว์เซอร์ (รีเฟรชแล้วไม่หาย)
  พอกดชำระแล้วจึงบันทึกลงฐานข้อมูล พร้อมได้เลขบิล `POS-ปีเดือนวัน-ลำดับ`
- **โปรโมชั่น:** หอยลายแม่ไอซ์ คละรส 2=135, 3=200, 4=260, 8=505
  ถ้าซื้อจำนวนที่อยู่ระหว่างขั้นโปร ระบบเลือกชุดที่ถูกที่สุดให้ เช่น 5 ชิ้น = 4+1 = 329
  pop-up ถามครั้งเดียวต่อบิล และในบิลมีปุ่มสลับใช้/ไม่ใช้โปร
  ยอดเงินคำนวณซ้ำที่ server เสมอ
- **ปิดร้าน:** กรอกเงินสดนับจริง ระบบคำนวณส่วนต่างให้ แล้วส่งอีเมล์สรุป
  (nattamon@thairoyalcoconut.com ล็อคไว้เป็นผู้รับหลัก เพิ่มผู้รับได้สูงสุดรวม 10 คน)
  หลังปิดร้าน บิลและค่าใช้จ่ายของรอบนั้นแก้ไขไม่ได้
- **รายงาน:** เลือกช่วงวันที่ / งาน Event ได้ แสดงยอดรวม เงินสด/โอน สินค้าขายดี
  ยอดตามงาน และรายการบิลทั้งหมด
